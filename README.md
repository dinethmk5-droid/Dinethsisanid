# 𝑫𝑰𝑵𝑬𝑻𝑯_𝑴𝑫_𝑴𝑰𝑵𝑰_𝑩𝑶𝑻 SESSIONS

Pair Code / QR මගින් WhatsApp SESSION ID එකක් හදන වෙබ් සයිට් එක.
SESSION ID = `creds.json` හි base64 (Flash-MD බොට් එකේ `SESSION` variable එකට ගැලපෙනවා).

## Railway deploy
1. මේ ෆෝල්ඩර් එක GitHub repo එකකට push කරන්න.
2. Railway → New Project → Deploy from GitHub repo.
3. Settings → Networking → Generate Domain.
4. Variables අවශ්‍ය නැහැ (PORT Railway එකෙන්ම දෙනවා).

## Local run
```
npm install
npm start
```
